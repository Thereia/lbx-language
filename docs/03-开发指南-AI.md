# 用 LBX 写程序（给编程 Agent）

照着这份文档能写出**可直接运行**的 LBX 程序。全部命令在仓库根目录执行。

> 本文件按 Skill 格式撰写：开头的 `---` 字段是 skill 元数据。要用它时把本文件复制成
> `<skills 目录>/lbx/SKILL.md` 即可被 Agent 自主触发；也可以直接让 Agent 读这个路径。
> 语法与语义的**权威**是 [01-语法规则.md](01-语法规则.md)，本文件是它的可操作子集。

## 0. 一个完整的 LBX 程序

```lbx
// 猜数字游戏的核心逻辑（结构 + 函数 + 循环 + 数组 + 输入输出全用上）
type Record = { name = "", score = 0 };

func judge(guess, answer)
    if guess == answer
        return "正确";
    elif guess < answer
        return "偏小";
    else
        return "偏大";
    end
end

func main()
    answer = 42;
    history = [];
    tries = 0;
    while tries < 5
        guess = int(input("请输入数字："));
        tries = tries + 1;
        push(history, guess);
        result = judge(guess, answer);
        print("第 ${tries} 次：${guess} → ${result}");
        if result == "正确"
            r = Record { name = "玩家", score = 5 - tries };
            print("猜中！得分 ${r.score}，历史 ${str(history)}");
            return;
        end
    end
    print("机会用尽，答案是 ${answer}");
end

main();
```

运行它（编译一次即可，之后只跑第二条）：

```
javac -encoding UTF-8 -d build src\lbx\*.java
java -cp build lbx.Main 你的脚本.lbx
```

## 1. 工作流程

### 步骤 1 —— 写脚本

每条语句以 `;` 结束；`if` / `while` / `for` / `func` 用 `end` 收尾。缩进只是给人看的，随便。

**完成标准**：文件里每个 `if` / `while` / `for` / `func` 都能数出一个配对的 `end`。

### 步骤 2 —— 先跑起来

```
java -cp build lbx.Main 你的脚本.lbx
```

**完成标准**：退出码为 0，**并且 stdout 与你预期逐行一致**。"没有报错"不算通过——输出内容不对同样是 bug。

### 步骤 3 —— 出错时按前缀定位

错误只有三种前缀，按前缀去第 4 节对应的表查：

| 前缀 | 阶段 | 附带信息 | 典型原因 |
|---|---|---|---|
| `[LBX 词法错误]` | 读字符 | 行、列 | 出现了 LBX 不认识的符号、字符串/注释没闭合 |
| `[LBX 语法错误]` | 读结构 | 行、列 | 漏分号、漏 `end`、语法形式不对 |
| `[LBX 运行时错误]` | 执行 | 行 | 未定义变量、类型不对、下标越界、除零 |

**完成标准**：脚本重跑后退出码 0，且错误消息不再出现。

### 步骤 4 —— 交付前自检

逐条过第 6 节的清单。**完成标准**：清单每一条都勾得上，且脚本是本机真跑过的。

## 2. 语法卡片

### 2.1 程序结构

顶层是语句序列，自上而下执行。`func` 与 `type` **只能写在最外层**，且**定义即注册**——
函数可以互相调用，也可以先调用后定义。

### 2.2 值与类型

| 类型 | 字面量 | `typeof(x)` |
|---|---|---|
| 整数 | `42`、`-7`（负号是一元运算符） | `int` |
| 字符串 | `"abc"`（可跨行） | `string` |
| 布尔 | `true` / `false` | `bool` |
| 空 | `null` | `null` |
| 数组 | `[1, "a", [2]]` | `array` |
| 结构 | `Point { x = 1 }` | `struct` |
| 函数 | 由 `func` 定义 | `function` |

**整数是唯一的数值类型**，没有浮点：`/` 是整除（`10 / 3` 得 `3`），`%` 取余。
需要小数效果时把数字放大成整数运算（例如金额按"分"存）。

### 2.3 运算符（优先级由低到高）

| 级 | 运算符 | 说明 |
|---|---|---|
| 1 | `or` | 两侧必须是 bool，短路 |
| 2 | `and` | 两侧必须是 bool，短路 |
| 3 | `not` | 一元，操作数必须是 bool |
| 4 | `==` `!=` | 类型不同时 `==` 得 `false`（不报错）；数组/结构比较引用 |
| 5 | `<` `<=` `>` `>=` | 只支持 int 与 int、string 与 string（字典序） |
| 6 | `+` `-` | `int + int` 得 int；`string + string` 得拼接；混合类型**报错** |
| 7 | `*` `/` `%` | 仅 int |
| 8 | 一元 `-` | 仅 int |
| 9 | `.` `[]` `()` | 字段、下标、调用（最紧） |

**没有** `+=` `-=` `++` `--`、没有三元 `? :`、没有字符串下标 `s[0]`。递增写成 `i = i + 1;`。

### 2.4 语句形式

```lbx
x = 1;                       // 首次赋值即声明变量（没有 var / let）
a[0] = 9;                    // 数组元素赋值
p.x = 3;                     // 结构字段赋值（字段必须在 type 里声明过）
print(x);                    // 表达式语句
;                            // 空语句，合法

if 条件
    ...
elif 条件
    ...
else
    ...
end

while 条件
    ...
end

for 元素变量 in 数组
    ...
end

break;                       // 只能在循环体内
continue;                    // 只能在循环体内
return;                      // 只能在函数体内；不带值时必须紧跟分号
return 表达式;

func 名字(参数, 参数)
    ...
end

type 名字 = { 字段 = 默认值, 字段 = 默认值 };    // 默认值必填
```

### 2.5 数组与结构

- 数组：下标从 `0` 开始，`len(a)` 取长度，`push(a, v)` 尾部追加（返回新长度），`pop(a)` 弹出尾部。
  **数组是引用语义**：传进函数后 `push` 会影响调用方看到的那一份。
- 结构：`type Point = { x = 0, y = 0 };` 声明后，`Point {}` 全取默认值，`Point { x = 3 }` 只覆盖 x。
  字段顺序就是打印顺序。**结构也是引用语义**，把结构传给函数、函数里改字段，调用方看得到。
- 读或写**没有声明的字段**会报运行时错误。

### 2.6 函数

- 参数个数必须与形参个数一致。
- 参数按值传递：int / string / bool / null 是复制；数组 / 结构传的是引用。
- 函数执行到 `end` 或 `return;` 都返回 `null`。
- 递归深度上限 **1000** 层，超出报「递归过深」。
- **函数不是值**：不能把函数当参数传、不能存进数组、没有 lambda。
- 没有重载、没有默认参数、没有可变参数。

### 2.7 字符串与插值

```lbx
s = "你好，" + name;              // 拼接用 +
print("共 ${len(a)} 条");         // ${ 表达式 } 插值，里面可以写任意表达式
print("字面量 \${x}");            // \${ 表示不插值
print("转义：\\ \" \n \t");
```

插值里字符串按 §8 规则转文本：字符串不加引号，数组/结构用带引号的形式
（`"${[1, "a"]}"` → `[1, "a"]`）。

### 2.8 内置函数（全部 9 个，没有别的）

| 调用 | 返回 | 说明 |
|---|---|---|
| `print(值, ...)` | null | 各参数用单个空格连接后输出一行；`print();` 只输出一个换行 |
| `input()` / `input("提示")` | string | 读一行（去掉行尾换行）；**读到文件结尾返回 null** |
| `len(数组或字符串)` | int | 元素个数 / 字符个数（中文按字算） |
| `int(值)` | int | `int("42")`、`int(true)` → 1；字符串不是整数形式会报错 |
| `str(值)` | string | 转成文本 |
| `typeof(值)` | string | 类型名。**注意是 `typeof`，`type` 是声明结构的关键字** |
| `push(数组, 值)` | int | 尾部追加，返回新长度 |
| `pop(数组)` | 值 | 弹出尾部；空数组报错 |
| `range(n)` / `range(a, b)` / `range(a, b, step)` | array | 整数序列，左闭右开；`range(3)` → `[0, 1, 2]` |

### 2.9 注释与空白

```lbx
// 行注释
/* 块注释，可以跨行 */
```

换行、缩进、空行全是空白，**语句边界只由 `;` 决定**。一行可以写多条语句，一条语句也可以跨多行
（表达式在运算符后换行即可）。

### 2.8a 库里没有的东西

上面就是全部函数，**没有标准库、没有 import**。下面这些都要自己写：

| 需要 | 怎么办 |
|---|---|
| 随机数 | 自己维护种子的线性同余，见 §5「伪随机数」 |
| `abs` / `max` / `min` | 各写一个三行函数，见 §5「自写小工具」 |
| 幂 / 开方 / 三角函数 | 用整数运算自己实现需要的那部分（例如平方就是 `x * x`） |
| 时间 / 日期 | 没有；要"每次不同"的值就用 `input()` 或自己维护计数器 |
| 文件读写 | 没有；数据只能从 `input()` 进，结果只能从 `print()` 出 |
| 命令行参数 | 没有；用 `input()` 交互 |
| 网络 / 系统调用 | 没有 |

**结论：写程序前先把"我需要的能力里哪些 LBX 没有"列出来**，缺的就在脚本里自己实现成函数。

## 3. Python 习惯迁移表

| 脑子里想写的（Python） | LBX 写法 | 原因 |
|---|---|---|
| `if x:` | `if x != 0:` | 条件必须是 bool，不做真值判断 |
| `i += 1` | `i = i + 1;` | 没有复合赋值 |
| `a.append(v)` | `push(a, v);` | 数组操作是内置函数 |
| `len(a)` | `len(a)` | 一样 |
| `def f(a):` … | `func f(a)` … `end` | 没有冒号和缩进规则，用 `end` 收尾 |
| `elif` | `elif` | 一样（不是 `else if`） |
| `# 注释` | `// 注释` | 注释符号不同 |
| `f"{x}"` | `"${x}"` | 插值语法不同 |
| `type(x)` | `typeof(x)` | `type` 是声明结构的关键字 |
| `5 / 2 == 2.5` | `5 / 2 == 2` | 整除；没有浮点 |
| `None` | `null` | 名字不同 |
| `while True:` | `while true` … `end` | 小写、无冒号 |
| `for i in range(n):` | `for i in range(n)` … `end` | 无冒号 |
| 字典 `{"a": 1}` | `type T = { a = 1 };` 然后 `T {}` | 没有字典类型，用结构 |
| `sys.argv` | —— | 程序读不到命令行参数，需要交互就用 `input()` |
| `try/except` | —— | 没有异常处理语法；用条件判断提前规避 |
| `f(a, b)` 里传函数 | —— | 函数不是值 |

## 4. 常见错误手册

### 4.1 词法错误

| 错误消息 | 原因 | 修法 |
|---|---|---|
| `非法字符 'x'` | 出现了 LBX 不认识的符号（`@` `#` `$` 单用、全角标点等） | 删掉或换成合法符号 |
| `未闭合的块注释` | `/*` 没有配对的 `*/` | 补 `*/` |
| `未闭合的字符串` | 字符串缺少收尾的 `"`（字符串可跨行，所以报错位置是字符串开头） | 补 `"` |
| `整数超出范围：...` | 整数字面量太大 | 换小一点的数 |

### 4.2 语法错误

| 错误消息 | 原因 | 修法 |
|---|---|---|
| `期望 ';'，实际遇到 'x'` | 上一条语句末尾漏分号 | 在上一行末尾补 `;` |
| `期望 'end'，实际遇到 'x'` | 块没有闭合 | 补 `end` |
| `文件意外结束，缺少 'end'` | 文件末尾漏了 `end` | 补 `end` |
| `期望表达式，实际遇到 'x'` | 运算符后面没跟操作数，或写了空表达式 | 补上操作数 |
| `赋值号左边必须是变量、下标或字段` | 例如 `1 = 2;` | 左边写成变量/`a[i]`/`p.f` |
| `return 只能出现在函数体内` | 顶层写了 `return` | 放进 `func` 里 |
| `break 只能出现在循环体内` / `continue ...` | 循环外用了 | 放进 `while` / `for` 里 |
| `func 定义只能出现在最外层` / `type ...` | 在函数体里定义了函数/结构 | 移到最外层 |
| `字符串插值缺少配对的 '}'` | `${` 没有对应 `}` | 补 `}` |
| `字符串插值里有多余内容：...` | `${}` 里写了多个表达式或多余符号 | 一个 `${}` 里只放一个表达式 |

### 4.3 运行时错误

| 错误消息 | 原因 | 修法 |
|---|---|---|
| `未定义的变量 x` | 用之前没赋过值；或在函数里用了别处才定义的变量 | 先赋值再用，或作为参数传进来 |
| `除零` / `模零` | `/ 0` 或 `% 0` | 先判断除数不为 0 |
| `数组下标越界：i（长度 n）` | 下标超出 `0..n-1` | 检查循环边界与下标计算 |
| `下标必须是整数，实际是 string` | 用了非整数下标 | 下标用整数表达式 |
| `下标运算只能用于数组，实际是 struct` | 对结构用了 `[]` | 结构用 `.字段` |
| `字段访问只能用于结构，实际是 int` | 对非结构用了 `.` | 检查变量类型 |
| `条件必须是布尔值，实际是 int` | `if 1` 这种写法 | 写成比较或逻辑表达式 |
| `运算符 + 不支持 int 和 string` | 数字和字符串直接相加 | `str(n) + s`（字符串拼接两边都要是 string） |
| `运算符 < 不支持 int 和 string` | 数字和字符串比大小 | 先 `int(s)` 或 `str(n)` 统一类型 |
| `结构 T 没有字段 f` | 字段名拼错，或 `type` 里没声明 | 用声明过的字段名 |
| `未定义的结构类型 T` | 用了没声明的结构名 | 先 `type T = { ... };` |
| `函数 f 需要 n 个参数，实际给了 m 个` | 实参个数不符 | 对齐参数个数 |
| `不是函数，无法调用：int` | 变量名拼错，或与函数重名 | 检查名字 |
| `递归过深（超过 1000 层）` | 递归太深或忘了终止条件 | 改写成循环，或缩小规模 |
| `for 只能遍历数组，实际是 int` | 遍历了非数组 | 用 `range(n)` 造数组再遍历 |
| `len 不支持 int` | 对非数组/非字符串用 `len` | 检查参数类型 |
| `对空数组做 pop` | 数组已空还弹出 | 先判断 `len(a) > 0` |
| `无法把字符串 "x" 转成整数` | 字符串不是整数形式 | 用 `int()` 前确认内容，或改用字符串处理 |

## 5. 惯用法

```lbx
// 伪随机数：LBX 没有内置随机数，自己用一个种子维护线性同余状态
seed = 12345;
func nextRand()
    seed = (seed * 1103515245 + 12345) % 2147483648;   // 乘积仍在 long 范围内，不会溢出
    return seed;
end
func randRange(n)
    return nextRand() % n;                             // 返回 0 .. n-1
end

// abs / max / min 也没有，自己写
func abs(x)
    if x < 0
        return -x;
    end
    return x;
end
func max(a, b)
    if a > b
        return a;
    end
    return b;
end
func min(a, b)
    if a < b
        return a;
    end
    return b;
end

// 累加与计数
total = 0;
count = 0;
for x in nums
    total = total + x;
    count = count + 1;
end

// 交换两个元素（LBX 没有并行赋值，要借临时变量）
t = a[i];
a[i] = a[j];
a[j] = t;

// 按索引遍历（需要下标时）
i = 0;
while i < len(a)
    print("第 ${i} 个：${a[i]}");
    i = i + 1;
end

// 结构数组（记录表）——最常用的数据组织方式
type Item = { name = "", score = 0 };
items = [];
push(items, Item { name = "张三", score = 88 });
for it in items
    print("${it.name}：${it.score}");
end

// 字符串拼装（每段都要是 string）
line = "";
for x in nums
    line = line + str(x) + ",";
end
print(line);

// 读取输入直到文件结尾
while true
    s = input();
    if s == null
        break;
    end
    print("读到：${s}");
end

// 早返回，避免深嵌套
func grade(s)
    if s >= 90
        return "A";
    end
    if s >= 60
        return "B";
    end
    return "C";
end
```

**可复用的排序模板**（冒泡，升序）：

```lbx
func sortAsc(a)
    n = len(a);
    i = 0;
    while i < n - 1
        j = 0;
        while j < n - 1 - i
            if a[j] > a[j + 1]
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            end
            j = j + 1;
        end
        i = i + 1;
    end
    return a;
end
```
