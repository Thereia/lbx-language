## 2. LBX 是一门什么样的语言

LBX 是这门课的大作业：从词法分析一路写到求值器的自研脚本语言。它的设计取向是
**"够用、可实现、讲得清"**，而不是功能堆叠。具体体现为三条：

1. **语法只有一种写法**。没有可选分号、没有多种循环形式、没有语法糖。
   这样做的收益不只是代码短——是**语言的行为完全可预测**，写出来的程序不会有"这里到底算不算一条语句"的含糊地带。
2. **类型规则严格**。条件必须是布尔值，整数和字符串不能相加。宁可当场报错，也不要"看起来跑通了但结果是怪"。
3. **能力边界明确**。没有浮点、没有字典、没有类、没有异常、函数不是值——这些都在第 8 节列清楚了。
   一门语言的"不做什么"和"做什么"一样是设计内容。

## 3. 第一个程序

新建 `hello.lbx`：

```lbx
print("Hello, LBX!");
print("1 + 2 * 3 = " + str(1 + 2 * 3));
```

编译一次解释器，然后运行脚本（在仓库根目录）：

```
javac -encoding UTF-8 -d build src\lbx\*.java
java -cp build lbx.Main hello.lbx
```

输出：

```
Hello, LBX!
1 + 2 * 3 = 7
```

注意第二行：`1 + 2 * 3` 是整数，要和字符串拼接必须先用 `str()` 转成字符串——
这就是第 4 节要讲的"严格类型"。

### 3.1 看见语言内部：两个调试开关

你写词法分析实验时，程序会打印记号流；LBX 的解释器把这件事做成了显式开关，
用来观察"你的源码在解释器眼里是什么样"：

```
java -cp build lbx.Main --tokens examples/demo-tokens.lbx
  1:1   IDENT    print
  1:6   OP       (
  1:7   STR      "hi"   hi
  1:11  OP       )
  1:12  OP       ;
  2:1   EOF

java -cp build lbx.Main --ast examples/demo-ast.lbx
BLOCK
  IF
    BIN (==)
      VAR (x)
      INT = VInt[v=1]
    BLOCK
      EXPR
        CALL
          VAR (print)
          BIN (+)
            STR = VStr[v=a]
            ...
```

这两个开关在**排查"我写的表达式为什么算错了"**时特别有用：看树里运算符的嵌套关系，
就能确认优先级是不是你想要的（`1 + 2 * 3` 的加号在树的上层，说明先算了乘法）。

## 4. 语言速成（每条都带设计原因）

### 4.1 语句以 `;` 结束，块以 `end` 收尾

```lbx
if x > 0
    print("正数");
    y = x * 2;
end
```

**为什么强制分号**：换行因此完全变成普通空白，词法分析器不必产生"换行记号"，
语法分析器也不必处理"表达式里的换行算不算结束"这种经典歧义（想想
`x = f(1)` 换行接 `(2)` 该算调用还是两条语句）。代价是多敲一个字符，换来少一整节规则。

**为什么用 `end` 而不是花括号或缩进**：花括号要处理"表达式里的 `{}`（结构字面量）和块的开头怎么区分"；
缩进要维护缩进栈。`end` 让块的开始和结束都是关键字，语法分析器只要数关键字。

**结果就是**：一行可以写多条语句，一条语句也可以跨多行。缩进随便写，只影响好不好看。

### 4.2 变量：首次赋值即声明

```lbx
count = 0;          // 第一次赋值就是声明
count = count + 1;  // 之后就是修改
```

没有 `var` / `let`。**为什么**：少一个关键字，而且作用域规则可以用两句话说完（见 4.7）。

### 4.3 数据类型与"打印出来长什么样"

| 类型 | 写法 | 打印出来 |
|---|---|---|
| 整数 | `42`、`-7` | `42` |
| 字符串 | `"abc"` | `abc`（**不加引号**） |
| 布尔 | `true` / `false` | `true` |
| 空 | `null` | `null` |
| 数组 | `[1, "a", [2]]` | `[1, "a", [2]]`（**里面的字符串带引号**） |
| 结构 | `Point { x = 1 }` | `Point { x = 1, y = 0 }` |

**为什么字符串在两处不一样**（外层不加引号、容器内加引号）：这是为了让两种需求同时成立——
`print("abc")` 应该是给人看的文本 `abc`，而 `print(["abc"])` 要能看出元素是字符串而不是变量名。
所以语言规定了两套转换：对外的 `str()` 和对容器内的带引号形式。

**这条要记住，因为黑盒测试是逐字节比对的**——你的程序输出必须和期望完全一致，
包括空格和引号。三个例子：

```lbx
print("abc", 1);        // abc 1
print(["abc", 1]);      // ["abc", 1]
print();                // 只输出一个空行
```

### 4.4 运算符：严格类型，没有隐式转换

优先级由低到高：`or` → `and` → `not` → `== !=` → `< <= > >=` → `+ -` → `* / %` → 一元 `-` → `. [] ()`。

三条最容易踩的规则：

```lbx
print(10 / 3);           // 3    ← 整除！整数是唯一的数值类型，没有浮点
print(1 + "a");          // 运行时错误：运算符 + 不支持 int 和 string
print(str(1) + "a");     // 1a   ← 正确写法
if 1                     // 运行时错误：条件必须是布尔值，实际是 int
```

**为什么整数是唯一的数值类型**：加浮点会牵动一整串设计——字面量怎么读（`1.` 合法吗）、
混合运算怎么提升类型（`1 + 2.0` 得什么）、打印怎么格式化（`2.0` 打 `2` 还是 `2.0`）、
整除语义怎么改。作业要求是"整数，字符串**等**基本数据类型"，所以选了最省事且够用的方案。

**为什么不做隐式转换**：`"5" + 1` 在 Python 里报错、在 JS 里得 `"51"`——同一行代码在两种语言里
两种结果，这类含糊正是严格规则要消灭的东西。

### 4.5 分支与循环

```lbx
if score >= 90
    grade = "A";
elif score >= 80
    grade = "B";
else
    grade = "C";
end

i = 0;
while i < 5
    i = i + 1;
    if i == 3
        continue;      // 跳过本次
    end
    if i == 5
        break;         // 结束循环
    end
    print(i);
end

for n in [10, 20, 30]
    print(n);
end

for i in range(0, 10, 2)
    print(i);          // 0 2 4 6 8
end
```

- 没有 `else if`，是 `elif`；没有 C 风格的 `for (i=0; i<n; i++)`，要用 `while`。
- `break` / `continue` 只能在循环体内，`return` 只能在函数体内——写错位置**在语法阶段就报错**，
  不会等到运行时才发现。
- **没有** `+=` `++` `--`，递增一律写 `i = i + 1;`。

### 4.6 数组与结构

```lbx
a = [1, "two", [3, 4]];
print(len(a), a[0], a[2][1]);    // 3 1 4
a[0] = 99;
push(a, 5);                      // 尾部追加，返回新长度
print(pop(a));                   // 弹出尾部 → 5

type Point = { x = 0, y = 0 };
p = Point {};                    // 全取默认值
q = Point { x = 3 };             // y 仍是 0
print(q.x + q.y);                // 3
q.y = 10;
print(q);                        // Point { x = 3, y = 10 }
```

三个要点：

- **下标从 0 开始**，越界报运行时错误（不是静默返回空）。
- **结构的字段默认值写在 `type` 声明里**。这让 `Point {}` 合法，构造时不必写全字段。
- **数组和结构是引用语义**：赋值、传参都是共享同一份。这条一定要理解透：

```lbx
func addOne(arr)
    push(arr, 1);
end
a = [];
addOne(a);
print(a);        // [1]     ← 函数里改了，外面看得见
```

同一个规则用在结构上：把结构传给函数、函数里改字段，调用方也看得见。

### 4.7 函数与作用域

```lbx
func fib(n)
    if n < 2
        return n;
    end
    return fib(n - 1) + fib(n - 2);
end
print(fib(10));    // 55
```

- **定义即注册**：解释器先把所有函数登记好再执行，所以**可以互相递归**，也可以先调用后定义。
- **函数只能写在最外层**（不能在函数里定义函数）。
- 参数按值传递（数组/结构传引用）；实参个数必须与形参一致；递归深度上限 1000 层。
- **函数不是值**：不能把函数当参数传、不能存进数组。所以没有回调、没有高阶函数。

作用域只有两条规则（找不到变量时按下表理解就不会错）：

| 情况 | 行为 |
|---|---|
| 读一个变量 | 从内到外找最近的定义，找不到就报「未定义的变量」 |
| 给一个变量赋值 | 从内到外找**最近的同名变量**并改它（所以函数里能直接改全局变量）；一个都没有才在当前作用域新建 |

```lbx
g = 1;
func bump()
    g = g + 10;      // 改的是全局那个 g
    local = 5;       // 新建：只在这个函数里存在
    return g + local;
end
print(bump(), g);    // 16 11
```

**注意**：循环和 `if` **不产生新作用域**。所以循环变量循环结束后还在：

```lbx
for i in [7, 8]
end
print(i);            // 8
```

**为什么这么设计**：作用域只有"全局"和"函数"两层，实现就是往一个栈里压/弹一层哈希表，
语义可以用上表两行说完。代价就是上面这两条"不太像 Python"的行为，文档写清楚即可。

### 4.8 字符串与插值

```lbx
name = "泊鑫";
print("你好，" + name + "！");        // 拼接用 +
print("你好，${name}！");             // 插值，结果一样
print("共 ${len(name)} 个字");        // 插值里可以写任意表达式
print("字面量 \${name}");            // \${ 表示不插值 → 字面量 ${name}
```

转义支持 `\n` `\t` `\\` `\"` `\$`。字符串**可以跨行**（代价是漏写收尾引号时，
报错位置会在字符串开头而不是行尾）。

### 4.9 内置函数（就这 9 个）

`print`、`input`、`len`、`int`、`str`、`typeof`、`push`、`pop`、`range`。

参数的完整规则见 [03-开发指南-AI.md](03-开发指南-AI.md) 的 §2.8 表。两条容易记错的：

- 取类型名的函数叫 **`typeof`**，不叫 `type`——`type` 已经是"声明结构类型"的关键字了。
- `input()` 读到输入结束（EOF）返回 `null`，所以循环读输入要判空。

## 5. 常见任务怎么做

```lbx
// ① 求和与计数
total = 0;
for x in nums
    total = total + x;
end
print("和 = ${total}，个数 = ${len(nums)}");

// ② 交换（没有并行赋值，要借临时变量）
t = a[i];
a[i] = a[j];
a[j] = t;

// ③ 结构数组：最常用的数据组织方式（LBX 没有字典和类）
type Item = { name = "", score = 0 };
items = [];
push(items, Item { name = "张三", score = 88 });
for it in items
    print("${it.name}：${it.score}");
end

// ④ 按分数排序（冒泡，降序）
func sortDesc(a)
    n = len(a);
    i = 0;
    while i < n - 1
        j = 0;
        while j < n - 1 - i
            if a[j].score < a[j + 1].score
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            end
            j = j + 1;
        end
        i = i + 1;
    end
    return a;
end

// ⑤ 交互循环：读到 EOF 为止
while true
    line = input("> ");
    if line == null
        break;
    end
    print("你输入了：${line}");
end
```

**想要能直接跑起来的完整范例**：`examples/features.lbx`（覆盖全部功能，14 行输出）、
`examples/guess.lbx`（带输入交互的猜数字）、`examples/fib.lbx`（递归与循环两种写法）。

## 6. 出错了怎么办

### 6.1 三类错误，看前缀就知道该查哪里

| 前缀 | 意思 | 你该看的 |
|---|---|---|
| `[LBX 词法错误] 行 L, 列 C` | 某个字符/记号本身不认识 | 是不是打了非法符号、字符串或注释没闭合 |
| `[LBX 语法错误] 行 L, 列 C` | 结构的组合方式不对 | 通常是漏 `;` 或漏 `end` |
| `[LBX 运行时错误] 行 L` | 跑到某一步才发现不对 | 变量没定义、类型不对、下标越界、除零 |

完整的"错误消息 → 原因 → 修法"对照表在 [03-开发指南-AI.md](03-开发指南-AI.md) 第 4 节，共 30 多条。

### 6.2 退出码

| 退出码 | 含义 |
|---|---|
| 0 | 正常跑完 |
| 1 | 有错误（词法 / 语法 / 运行时） |
| 2 | 用法错误（没给脚本路径、文件不存在） |

所以写脚本跑批时可以靠退出码判断成败——黑盒测试就是这么做的。

### 6.3 调试手法

1. **先缩小**：把可疑的几行单独放进一个 `.lbx` 跑一遍。
2. **用 `--ast` 看优先级**：表达式算错时，看树里运算符的嵌套是不是你想要的那棵。
3. **用 `--tokens` 看记号**：字符串/插值/注释出问题时，看记号是不是被切成了你以为的样子。
4. **插 `print`**：LBX 没有调试器，但每个中间值都可以 `print(typeof(x), x);` 看一眼。

## 7. 一个完整例子：逐段读 `examples/guess.lbx`

```lbx
type Record = { name = "", score = 0 };          // ① 结构类型：字段带默认值

func judge(guess, answer)                        // ② 纯函数：只靠参数与返回值
    if guess == answer
        return "正确";
    elif guess < answer
        return "偏小";
    else
        return "偏大";
    end
end

func main()                                      // ③ 主流程：读输入、循环、早返回
    answer = 42;
    history = [];
    tries = 0;
    while tries < 5
        guess = int(input("请输入数字："));        // ④ input 读字符串，int 转整数
        tries = tries + 1;
        push(history, guess);                    // ⑤ 数组是引用语义，直接用
        result = judge(guess, answer);
        print("第 ${tries} 次：${guess} → ${result}");
        if result == "正确"
            r = Record { name = "玩家", score = 5 - tries };   // ⑥ 结构字面量
            print("猜中！得分 ${r.score}，历史 ${str(history)}");
            return;                              // ⑦ 早返回，不再往下走
        end
    end
    print("机会用尽，答案是 ${answer}");
end

main();                                          // ⑧ 顶层调用入口
```

几个可以照着学的习惯：

- **用 `return` 早返回**，而不是把整段逻辑塞进一层层 `if` 里；
- **把判断逻辑抽成无副作用的函数**（`judge` 只依赖参数），主流程只负责输入输出；
- **用结构而不是一堆平行变量**（`Record` 比 `name`、`score` 两个散变量清楚）；
- `main()` 这类入口函数要**显式调用**——LBX 不会自动执行某个函数，顶层语句是按顺序执行的。

## 8. 能力边界：这些写法 LBX 不支持

| 不支持 | 替代写法 |
|---|---|
| 浮点 / 小数 | 整数放大后运算（金额按分存），或专门处理商与余数 |
| 字典 / 映射 | 结构（字段固定）或"键数组 + 值数组"两个平行数组 |
| 类 / 对象 / 继承 | 结构 + 函数（函数第一个参数当"self"传） |
| 异常处理 `try` | 先用条件判断规避（如除之前判 0、取下标前判范围） |
| 函数作为值 / lambda / 回调 | 用 `if`/`elif` 分支选择要执行的逻辑 |
| 命令行参数 | 用 `input()` 交互输入 |
| 模块 / import | 所有代码写在一个 `.lbx` 文件里 |
| 位运算 `&` `\|` `^` `<<` | 用算术运算替代 |
| 复合赋值 `+=`、自增 `++` | `i = i + 1;` |
| 三元 `a ? b : c` | `if`/`else` 给变量赋值 |
| 字符串下标 `s[0]` | 没有；需要逐字符处理时用 `len` 与 `input` 的整行文本另做处理 |
| 多返回值 | 用结构把多个值装起来返回 |
| `break` 一次跳出多层循环 | 用标志变量，外层循环判断标志后 `break` |
| 随机数 | 没有内置随机数；自己用线性同余实现（范例见 [03-开发指南-AI.md](03-开发指南-AI.md) §5） |
| `abs` / `max` / `min` / 幂 / 开方 | 没有数学库，各写一个几行的函数 |
| 时间、日期 | 没有；需要"变化的值"就用 `input()` 或自己的计数器 |
| 文件读写、网络 | 没有；数据从 `input()` 进、结果从 `print()` 出 |

这份边界不是"做不到"，而是**为"可实现、讲得清"付的代价**：每一条都意味着解释器里少一整块机制
（类型提升、哈希表、闭包捕获、异常展开、模块加载……）。
