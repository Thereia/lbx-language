## 1. 语言定位

| 项目 | 说明 |
|---|---|
| 名称 | **LBX**（取自设计者姓名"刘泊鑫"的拼音首字母） |
| 实现方式 | **解释型**：源码 → 词法分析 → 语法分析（建语法树）→ 遍历语法树求值；全程不生成任何中间可执行文件 |
| 类型系统 | **动态类型**：变量无类型，值有类型，类型在运行时确定 |
| 用途 | 通用脚本语言（图灵完备，可写任意程序），面向命令行脚本与小工具 |
| 作用域 | 全局作用域 + 函数局部作用域（作用域链） |
| 源文件 | 扩展名 `.lbx`，编码 **UTF-8 无 BOM** |

## 2. 语言特色（与现有语言的差异点）

作业要求"不能与现存的任何程序设计语言完全相同"。LBX 不追求单项创新，而是用下面这组**组合**形成自己的面貌
（任何单一语言都没有同时具备这几条）：

| # | 特色 | 与谁像、又哪里不同 |
|---|---|---|
| 1 | **语句以 `;` 结束、块以 `end` 收尾**：没有花括号、不要求缩进，换行与空格完全等价 | 像 Lua/Ada 的 `end`，但 LBX 是强制分号 + 严格布尔条件 + 整数整除与浮点提升并存的组合 |
| 2 | **`${}` 字符串插值**内建于字符串字面量 | 类似 JS 模板串，但 LBX 用双引号，且插值内可写任意表达式 |
| 3 | **`type` 声明结构类型并带字段默认值**，结构字面量可省略字段 | 类似 Rust/Swift 的结构体，但字段默认值使 `Point { x = 3 }` 合法 |
| 4 | **严格类型运算**：条件必须是布尔值，不做隐式转换，数值与字符串不可相加 | 与 Python/JS 的宽松真值判断相反 |
| 5 | **无 `var`/`let`**：首次赋值即声明 | 像 Python，但查找/新建规则在 §7.3 中被精确定义 |
| 6 | **数值类型只有 `int` 与 `float` 两个**：两个整数之间 `/` 是整除，只要出现浮点就按实数运算；没有隐式转换（`1 + "a"` 报错），但两个数值类型之间会互相提升 | 主流脚本语言要么只有浮点（JS）、要么整除要写成 `//`（Python）；LBX 用「有没有小数点」决定语义 |

## 3. 词法规则

### 3.1 空白、换行与注释

- 空格、制表符 `\t`、回车 `\r`、换行 `\n` **一律作为空白忽略**。
- **换行不产生任何记号**：语句边界完全由 `;` 决定（见 §6.2），因此多行书写表达式、缩进风格都纯属自由。
  换行仍会被词法分析器计数，用于给错误定位行号。
- 行注释：`//` 到行尾（`\r\n` 或 `\n` 之前的内容全部忽略）。
- 块注释：`/*` 到 `*/`，可跨行，**不支持嵌套**；未闭合的块注释报词法错误。
- ⚠️ 本语言**没有 `//` 整除运算符**——两个整数之间的 `/` 本身就是整除，`//` **永远**是行注释。

### 3.2 标识符与关键字

- 标识符：`[A-Za-z_][A-Za-z0-9_]*`，只允许 ASCII 字母、数字、下划线（**不支持中文标识符**）。
- **最长匹配 + 关键字优先**：先按最长匹配切出完整标识符，再查关键字表；命中即为关键字，否则为标识符。
  因此 `iffy` 是标识符而不是 `if` + `fy`（沿用词法分析实验的既有做法）。

关键字表（共 17 个，全部为英文）：

| 关键字 | 含义 | 关键字 | 含义 | 关键字 | 含义 |
|---|---|---|---|---|---|
| `func` | 函数定义 | `return` | 返回 | `type` | 结构类型定义 |
| `end` | 块结束 | `break` | 跳出循环 | `true` / `false` | 布尔字面量 |
| `if` | 分支 | `continue` | 继续下一次循环 | `null` | 空值 |
| `elif` | 否则如果 | `for` | 遍历循环 | `and` / `or` / `not` | 逻辑运算 |
| `else` | 否则 | `in` | 遍历目标 | | |
| `while` | 当型循环 | | | | |

运算符别名（接受但不推荐，仅为容错）：`&&` ≡ `and`，`||` ≡ `or`，`!` ≡ `not`。

### 3.3 字面量

| 类型 | 写法 | 规则 |
|---|---|---|
| 整数 | `0`、`42`、`1024` | 十进制正整数序列；**无符号**，负数由一元 `-` 得到；不支持 `0x`、八进制、指数 |
| 浮点 | `1.5`、`0.5`、`2.0` | 十进制数字 + `.` + 十进制数字，**小数点两侧都必须是数字**；不支持 `1.`、`.5`、`1e3`（见 §13 第 12 条）；无符号，负数由一元 `-` 得到 |
| 字符串 | `"abc"` | 双引号包裹，可跨行；转义 `\n` `\t` `\\` `\"` `\$`；`${ 表达式 }` 为插值（§7.5） |
| 布尔 | `true` / `false` | 关键字 |
| 空 | `null` | 关键字 |
| 数组 | `[1, "a", [2, 3]]` | `[` 元素列表 `]`，允许空数组 `[]`、允许嵌套、允许尾逗号 |
| 结构 | `Point { x = 3 }` | 类型名 + `{ 字段 = 值, ... }`，缺省字段取类型声明中的默认值 |

> **数值规则（v1.3）**：数值类型只有 `int` 与 `float`。两个 `int` 之间的 `+ - * / %` 保持整数语义
> （`/` 是整除、向零截断）；只要有一边是 `float`，就按实数运算，结果一定是 `float`。
> `1.` 与 `.5` 都不是浮点字面量：`.` 在词法上仍是一个独立记号，所以 `1.x` 会被解析成
> 「整数 1 + 字段访问 `.x`」。

(  )  [  ]  {  }  ,  ;                    .          //  /*  */

## 4. 数据类型

| 类型 | 类型名（`typeof(x)` 的返回值） | 字面量示例 | 语义 |
|---|---|---|---|
| 整数 | `"int"` | `42` | **值语义**（复制） |
| 浮点 | `"float"` | `1.5` | **值语义**（复制） |
| 字符串 | `"string"` | `"hi"` | **值语义**，且**不可变**（拼接产生新串） |
| 布尔 | `"bool"` | `true` | 值语义 |
| 空 | `"null"` | `null` | 值语义，唯一的空值 |
| 数组 | `"array"` | `[1, 2]` | **引用语义**（赋值、传参共享同一份） |
| 结构 | `"struct"` | `Point { x = 1 }` | **引用语义** |
| 函数 | `"function"` | 由 `func` 定义 | 引用语义 |

## 5. 运算符与优先级

优先级由低到高（同级左结合，另注明者除外）：

| 级别 | 运算符 | 结合性 | 运算规则 |
|---|---|---|---|
| 1 | `or` | 左 | 两侧必须为 bool，短路求值 |
| 2 | `and` | 左 | 两侧必须为 bool，短路求值 |
| 3 | `not` | 右（一元） | 操作数必须为 bool |
| 4 | `==` `!=` | 左 | 同类型比较；数组/结构比较**引用**（同一对象为 true）；**类型不同时 `==` 得 `false`、`!=` 得 `true`，不报错**。**例外**：`int` 与 `float` 之间按数值比较，所以 `1 == 1.0` 得 `true` |
| 5 | `<` `<=` `>` `>=` | 左 | `int` / `float` 之间按数值（任意组合）、`string` 与 `string`（字典序）合法；其他类型报运行时错误 |
| 6 | `+` `-` | 左 | 两个 `int` → int；任一边是 `float` → float；**`string + string` → 拼接**；数值与字符串等其他混合类型报错 |
| 7 | `*` `/` `%` | 左 | 两个 `int` → 整数运算，其中 `/` 为**整除**（向零截断）；任一边是 `float` → 实数运算；除零、模零报运行时错误 |
| 8 | 一元 `-` | 右 | `int` 或 `float`（结果同类型） |
| 9 | `.` `[]` `()` | 左 | 字段访问、下标、函数调用（后缀，最高优先级） |

括号 `( )` 可改变结合顺序。赋值 `=` **不是表达式**，只是语句（§6.1），因此 `a = b = 1` 非法。

## 6. 语句

### 6.1 语句种类

程序 = 顶层语句序列，自上而下执行；`func`、`type` 声明本身不产生输出。

```
赋值/表达式语句    x = 1;      a[0] = 2;      p.x = 3;      f(1);
分支              if 条件 ... elif 条件 ... else ... end
当型循环          while 条件 ... end
遍历循环          for 变量 in 数组 ... end
循环控制          break;      continue;
返回              return;      return 表达式;
函数定义          func 名字(参数...) ... end
结构类型定义      type 名字 = { 字段 = 默认值, ... };
空语句            ;
```

- **简单语句**（赋值、表达式、`return`、`break`、`continue`）和 `type` 声明**必须以 `;` 结束**。
- **块语句**（`if`、`while`、`for`、`func`）以 `end` 收尾，`end` 后**不要求** `;`；
  若写了 `;`，它被视为一个空语句，不报错。
- 单独一个 `;` 是**空语句**，可出现在任何语句位置（因此 `;;`、块首尾多余分号都合法）。
- 赋值左侧必须是**变量 / 下标 / 字段**，否则报语法错误（如 `1 = 2;`、`f() = 3;`）。
- `if` 允许 0 个或多个 `elif`，最多 1 个 `else`，必须以 `end` 收尾。
- `for` 的遍历目标是数组，循环变量在每轮取一个元素。
- `break`/`continue` 只能出现在循环体内，`return` 只能出现在函数体内，否则报语法错误。
- **条件表达式必须是 bool**（`if 1` 报运行时错误「条件必须是布尔值」）。

### 6.2 分号与换行

语句边界**只由 `;` 决定**，因此：

- 换行、缩进、空行完全自由，一行可以写多条语句，一条语句也可以跨多行：

```
x = 1; y = 2;              // 一行两条
total = 1 +
        2 +
        3;                 // 跨多行，合法
```

- 不带返回值的 `return` / `break` / `continue` 必须紧跟 `;`，写成 `return;` `break;` `continue;`；
  写成"关键字单独占一行"是不合法的（换行不再分句）：

```
return          // 语法错误：期望 ';' 或表达式
x;
```

### 6.3 完整语句示例

```
// 结构类型与函数
type Point = { x = 0, y = 0 };

func dist2(p, q)
    dx = p.x - q.x;
    dy = p.y - q.y;
    return dx * dx + dy * dy;
end

// 分支
score = 87;
if score >= 90
    grade = "A";
elif score >= 80
    grade = "B";
else
    grade = "C";
end
print("等级：" + grade);

// 当型循环
i = 0;
while i < 3
    print(i);
    i = i + 1;
end

// 遍历循环 + 数组 + 插值
nums = [3, 1, 4, 1, 5];
total = 0;
for n in nums
    total = total + n;
end
print("和 = ${total}，个数 = ${len(nums)}");

// 函数调用（递归）
func fib(n)
    if n < 2
        return n;
    end
    return fib(n - 1) + fib(n - 2);
end
print(fib(10));
```

## 7. 语义细则

### 7.1 函数定义与调用

- **定义即注册**：语法分析阶段先登记全部顶层函数，因此**支持互相递归**、支持"调用写在定义之前"。
- 调用时实参个数必须等于形参个数，否则运行时错误。
- 参数**按值传递**：int/string/bool/null 复制；array/struct 传递引用（函数内修改元素、字段会影响调用方）。
- 函数执行到 `end` 或执行 `return;`（不带表达式）都返回 `null`。
- **递归深度上限 1000**，超出报运行时错误「递归过深」（避免 JVM 栈溢出直接崩溃）。
- 不支持重载、默认参数、可变参数、匿名函数（v1.0）。

### 7.2 作用域

- 全局作用域 + 每次函数调用一个新的局部作用域（父作用域为全局）。
- 标识符解析：沿作用域链由内向外查找；查不到即运行时错误「未定义的变量 x」。
- 循环、`if` 块**不**产生新作用域（其内新建的变量属于所在函数/全局作用域），以保持实现简单、语义可预期。

### 7.3 赋值规则（无 var/let）

赋值 `名字 = 表达式;` 时：

1. 若 `名字` 已存在于当前作用域链 → 修改**最近**的那一个（因此函数内可直接改全局变量）；
2. 否则在**当前（最内层）作用域**新建该变量。

### 7.4 数组与结构

- 下标从 **0** 开始；下标必须是 int；越界或负数下标报运行时错误「数组下标越界」。
- `push(arr, v)` 在尾部追加，返回新长度；`pop(arr)` 弹出并返回尾部元素，空数组报错。
- 结构：`type Point = { x = 0, y = 0 };` 声明后，`Point { x = 3 }` 得到 `y = 0`。
- 读取或赋值**未声明的字段**报运行时错误；对非 struct 取字段也报错。
- 结构字段的**声明顺序**即打印顺序（§8）。

### 7.5 字符串插值

- `"共 ${ n + 1 } 条"`：`${` 与 `}` 之间是任意表达式，求值后按 `str()` 规则转成字符串拼接。
- `$` 后面不是 `{` 时原样输出；需要字面 `${` 时写 `\${`。
- 插值表达式内不能出现未配对的 `}`。

## 8. 输出格式（黑盒测试的逐字节基准，必须严格遵守）

`print(参数1, 参数2, ...)`：各参数按 `str()` 转换后用**单个空格**连接，**末尾输出一个换行**；无参数时只输出一个换行。

`str(x)` 的转换规则：

| 值的类型 | 转换结果 | 示例 |
|---|---|---|
| int | 十进制，负数带 `-` | `-42` |
| float | `Double.toString` 的最短往返表示：整数部分照写，**整数值也带一个小数点** | `2.0`、`0.5`、`0.3333333333333333` |
| string | 原文本，**不加引号** | `abc` |
| bool | `true` / `false` | `true` |
| null | `null` | `null` |
| array | `[` + 各元素**带引号的 repr** 用 `, ` 连接 + `]` | `[1, "a", [2]]` |
| struct | `类型名 { 字段 = repr, ... }`，按声明顺序用 `, ` 连接 | `Point { x = 3, y = 0 }` |
| function | `<func 名字>` | `<func fib>` |

其中**容器内**的元素用 repr 形式（字符串带双引号并对 `"`、`\`、换行转义），容器**外层**的字符串不加引号：

```
print("abc");            // abc
print(["abc", 1]);       // ["abc", 1]
print(Point { x = 1 });  // Point { x = 1, y = 0 }
print(1.0, [1.5, 2]);    // 1.0 [1.5, 2]
```

## 9. 内置函数

| 名称 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `print` | 任意个 | `null` | §8 |
| `input` | 0 或 1 个（提示串） | string | 先输出提示（不换行），读一行并去掉行尾换行；**读到 EOF 返回 null** |
| `len` | array / string | int | 元素个数 / 字符个数 |
| `int` | string / float / int / bool | int | 字符串须为可选 `-` + 数字（不接受 `"1.5"`），否则运行时错误；float 向零截断；bool 转 0/1 |
| `float` | string / int / float / bool | float | `float("2.5")` → 2.5、`float(3)` → 3.0、`float(true)` → 1.0；字符串须为可选 `-` + 数字（可带小数点） |
| `str` | 任意 | string | §8 规则 |
| `typeof` | 任意 | string | 类型名，见 §4。**注意不叫 `type`**：`type` 已是声明结构类型的关键字（§3.2），同名会导致该函数无法调用，见第 13 节第 10 条 |
| `push` | (array, 任意) | int | 尾部追加，返回新长度 |
| `pop` | array | 任意 | 弹出尾部元素；空数组报错 |
| `range` | `n` / `a, b` / `a, b, step` | array | 整数序列，左闭右开；`step` 不能为 0；`range(3)` → `[0, 1, 2]` |

调用不存在的函数、参数个数不符 → 运行时错误。

## 10. 运行方式、退出码与错误格式

### 10.1 命令行

```
java -cp target\classes lbx.Main 脚本路径.lbx
java -cp target\classes lbx.Main --tokens 脚本路径.lbx
java -cp target\classes lbx.Main --ast    脚本路径.lbx
```

前一条是正常执行；后两条分别是「只打印记号流」「只打印语法树」，供自测与验收讲解使用。

### 10.2 退出码

| 退出码 | 含义 |
|---|---|
| 0 | 程序正常执行完毕 |
| 1 | 词法 / 语法 / 运行时错误 |
| 2 | 命令行用法错误（未给脚本、文件不存在，等） |

### 10.3 错误消息格式

```
[LBX 词法错误] 行 3, 列 12: 未闭合的块注释
[LBX 语法错误] 行 7, 列 15: 期望 ';'，实际遇到 'end'
[LBX 语法错误] 行 9, 列 1: 期望表达式，实际遇到 ';'
[LBX 运行时错误] 行 12: 除零
[LBX 运行时错误] 行 20: 未定义的变量 total
```

- 行列号均为 **1 起算**；语法错误必须给出行、列，运行时错误至少给出行号。
- 每条错误一行；遇到第一个错误即终止（不做错误恢复）。
- 错误消息中的标识符与记号按原文给出。

## 11. 完整示例程序

```lbx
// guess.lbx —— 猜数字（覆盖输入输出、分支循环、函数、数组、结构、插值）
type Record = { name = "", score = 0 };

func judge(guess, answer)
    if guess == answer
        return "正确";
    elif guess < answer
        return "偏小";
    else
        return "偏大";
    end
end

func main()
    answer = 42;
    history = [];
    tries = 0;
    while tries < 5
        guess = int(input("请输入数字："));
        tries = tries + 1;
        push(history, guess);
        result = judge(guess, answer);
        print("第 ${tries} 次：${guess} → ${result}");
        if result == "正确"
            r = Record { name = "玩家", score = 5 - tries };
            print("猜中！得分 ${r.score}，历史 ${str(history)}");
            return;
        end
    end
    print("机会用尽，答案是 ${answer}");
end

main();
```

> **健壮性注记（v1.2 补充）**：上面这段示例假设输入总是充足——`int(input(...))` 在读到输入结束时
> 会得到 `null`，`int(null)` 报运行时错误。这是示例为了短而做的简化，不是语言规定。
> 写交互程序时请用安全读入模板：把「读一行 → 判空 → 比对白名单」收在一个函数里，
> 模板见 [03-开发指南-AI.md](03-开发指南-AI.md) §5.1。

## 12. 形式化文法（EBNF）

记号约定：`{ X }` 表示 0 或多次，`[ X ]` 表示可选，`|` 表示或，大写为词法记号，`"x"` 为字面记号。

```ebnf
program        → { top_stmt } EOF ;

top_stmt       → func_decl | type_decl | statement ;

(* ---------- 声明 ---------- *)
type_decl      → "type" IDENT "=" "{" [ field_defs ] "}" ";" ;
field_defs     → IDENT "=" expr { "," IDENT "=" expr } [ "," ] ;

func_decl      → "func" IDENT "(" [ params ] ")" { statement } "end" ;
params         → IDENT { "," IDENT } ;

(* ---------- 语句 ---------- *)
statement      → if_stmt | while_stmt | for_stmt
               | "break" ";"
               | "continue" ";"
               | "return" [ expr ] ";"
               | expr [ "=" expr ] ";"
               | ";" ;

if_stmt        → "if" expr { statement }
                 { "elif" expr { statement } }
                 [ "else" { statement } ]
                 "end" ;

while_stmt     → "while" expr { statement } "end" ;

for_stmt       → "for" IDENT "in" expr { statement } "end" ;

(* ---------- 表达式：优先级由低到高 ---------- *)
expr           → or_expr ;
or_expr        → and_expr { "or" and_expr } ;
and_expr       → not_expr { "and" not_expr } ;
not_expr       → "not" not_expr | equality ;
equality       → comparison { ( "==" | "!=" ) comparison } ;
comparison     → additive { ( "<" | "<=" | ">" | ">=" ) additive } ;
additive       → multiplicative { ( "+" | "-" ) multiplicative } ;
multiplicative → unary { ( "*" | "/" | "%" ) unary } ;
unary          → "-" unary | postfix ;
postfix        → primary { "." IDENT | "[" expr "]" | "(" [ args ] ")" } ;
args           → expr { "," expr } [ "," ] ;

primary        → INT | FLOAT | STRING | "true" | "false" | "null" | IDENT
               | "(" expr ")"
               | "[" [ args ] "]"                    (* 数组字面量 *)
               | IDENT "{" [ struct_fields ] "}" ;   (* 结构字面量 *)
struct_fields  → IDENT "=" expr { "," IDENT "=" expr } [ "," ] ;
```

> 实现提示：`statement` 中的 `expr [ "=" expr ] ";"` 在解析到 `=` 后需检查左侧是否为
> 变量/下标/字段（可赋值目标），否则报语法错误。
