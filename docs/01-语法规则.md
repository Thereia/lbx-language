## 1. 语言定位

| 项目 | 说明 |
|---|---|
| 名称 | **LBX**（取自设计者姓名"刘泊鑫"的拼音首字母） |
| 实现方式 | **解释型**：源码 → 词法分析 → 语法分析（建语法树）→ 遍历语法树求值；全程不生成任何中间可执行文件 |
| 类型系统 | **动态类型**：变量无类型，值有类型，类型在运行时确定 |
| 用途 | 通用脚本语言（图灵完备，可写任意程序），面向命令行脚本与小工具 |
| 作用域 | 全局作用域 + 函数局部作用域（词法作用域链） |
| 源文件 | 扩展名 `.lbx`，编码 **UTF-8 无 BOM** |

## 2. 语言特色（与现有语言的差异点）

作业要求"不能与现存的任何程序设计语言完全相同"，LBX 的个性由以下几条组合而成：

| # | 特色 | 与谁像、又哪里不同 |
|---|---|---|
| 1 | **`end` 收尾的块结构 + 换行分句**：没有花括号、不要求缩进、不要求分号 | 像 Lua 的 `end`，但 LBX 明确定义了"表达式内换行"规则（§6.2），并采用严格的布尔条件 |
| 2 | **中文关键字别名 + 允许中文标识符**：如 `函数 求阶乘(n) ... 结束` | 现存主流语言均无此特性 |
| 3 | **`${}` 字符串插值**内建于字符串字面量 | 类似 JS 模板串，但 LBX 用双引号且插值内可写任意表达式 |
| 4 | **`type` 声明结构类型并带字段默认值**，结构字面量缺省字段自动取默认值 | 类似 Rust/Swift 的结构体，但字段默认值使 `Point { x = 3 }` 合法 |
| 5 | **严格类型运算**：条件必须是布尔值，不做隐式转换，整数与字符串不可相加 | 与 Python/JS 的宽松真值判断相反 |
| 6 | **无 `var`/`let`**：首次赋值即声明 | 像 Python，但查找/新建规则在 §7.3 中被明确定义 |

## 3. 词法规则

### 3.1 空白、换行与注释

- 空格、制表符 `\t`、回车 `\r` 一律忽略。
- **换行**（`\n` 或 `\r\n`）产生一个 `NEWLINE` 记号，它是语句分隔符（§6.2）。
- 行注释：`//` 到行尾。
- 块注释：`/*` 到 `*/`，可跨行，**不支持嵌套**；未闭合的块注释报词法错误。
- 注释不产生记号；注释中的换行照常产生 `NEWLINE`。

### 3.2 标识符与关键字

- 英文标识符：`[A-Za-z_][A-Za-z0-9_]*`
- 中文标识符：首字符为汉字，后续可跟汉字、字母、数字、下划线（如 `学生名单`、`总分2`）
- **最长匹配 + 关键字优先**：先按最长匹配切出完整标识符，再查关键字表；命中即为关键字，否则为标识符。
  因此 `iffy` 是标识符而不是 `if` + `fy`（沿用词法分析实验的既有做法）。

关键字表（**规范写法 / 等价中文别名**，两种写法可自由混用）：

| 规范 | 中文别名 | 含义 | 规范 | 中文别名 | 含义 |
|---|---|---|---|---|---|
| `func` | `函数` | 函数定义 | `return` | `返回` | 返回 |
| `end` | `结束` | 块结束 | `break` | `跳出` | 跳出循环 |
| `if` | `如果` | 分支 | `continue` | `继续` | 继续下一次循环 |
| `elif` | `否则若` | 否则如果 | `type` | `类型` | 结构类型定义 |
| `else` | `否则` | 否则 | `true` / `false` | `真` / `假` | 布尔字面量 |
| `while` | `当` | 当型循环 | `null` | `空` | 空值 |
| `for` | `对于` | 遍历循环 | `and` / `or` / `not` | `且` / `或` / `非` | 逻辑运算 |
| `in` | `在` | 遍历目标 | | | |

> 约定：**测试集、文档示例、AI 生成的代码统一使用规范写法**；中文别名用于演示与答辩（§11.2 给出中文示例）。
> 运算符别名：`&&` ≡ `and`，`||` ≡ `or`，`!` ≡ `not`（接受但不推荐）。

### 3.3 字面量

| 类型 | 写法 | 规则 |
|---|---|---|
| 整数 | `0`、`42`、`1024` | 十进制正整数序列；**无符号**，负数由一元 `-` 得到；不支持 `0x`、八进制、浮点 |
| 字符串 | `"abc"` | 双引号包裹，可跨行；转义 `\n` `\t` `\\` `\"` `\$`；`${ 表达式 }` 为插值（§7.5） |
| 布尔 | `true` / `false` | 关键字 |
| 空 | `null` | 关键字 |
| 数组 | `[1, "a", [2, 3]]` | `[` 元素列表 `]`，允许空数组 `[]`、允许嵌套、允许尾逗号 |
| 结构 | `Point { x = 3 }` | 类型名 + `{ 字段 = 值, ... }`，缺省字段取类型声明中的默认值 |

> **v0 不含浮点类型**（见 §13 待确认项 2）。`+`、`-`、`*`、`/`、`%` 中的数值运算只针对整数。

### 3.4 运算符与分隔符

```
+  -  *  /  %      ==  !=  <  <=  >  >=      and  or  not      = 
(  )  [  ]  {  }  ,  .  ;  :            //  /*  */
```

## 4. 数据类型

| 类型 | 类型名（`type(x)` 的返回值） | 字面量示例 | 语义 |
|---|---|---|---|
| 整数 | `"int"` | `42` | **值语义**（复制） |
| 字符串 | `"string"` | `"hi"` | **值语义**，且**不可变**（拼接产生新串） |
| 布尔 | `"bool"` | `true` | 值语义 |
| 空 | `"null"` | `null` | 值语义，唯一的空值 |
| 数组 | `"array"` | `[1, 2]` | **引用语义**（赋值、传参共享同一份） |
| 结构 | `"struct"` | `Point { x = 1 }` | **引用语义** |
| 函数 | `"function"` | 由 `func` 定义 | 引用语义 |

## 5. 运算符与优先级

优先级由低到高（同级左结合，另注明者除外）：

| 级别 | 运算符 | 结合性 | 运算规则 |
|---|---|---|---|
| 1 | `or` | 左 | 两侧必须为 bool，短路求值 |
| 2 | `and` | 左 | 两侧必须为 bool，短路求值 |
| 3 | `not` | 右（一元） | 操作数必须为 bool |
| 4 | `==` `!=` | 左 | 同类型比较；数组/结构比较**引用**（同一对象为 true）；**类型不同时 `==` 得 `false`、`!=` 得 `true`，不报错** |
| 5 | `<` `<=` `>` `>=` | 左 | 仅 `int` 与 `int`（数值）、`string` 与 `string`（字典序）合法；其他类型报运行时错误 |
| 6 | `+` `-` | 左 | `int + int` → int；**`string + string` → 拼接**；`int + string` 等混合类型报错 |
| 7 | `*` `/` `%` | 左 | 仅 int；`/` 为**整除**（向零截断）；`%` 取余；除零、模零报运行时错误 |
| 8 | 一元 `-` | 右 | 仅 int |
| 9 | `.` `[]` `()` | 左 | 字段访问、下标、函数调用（后缀，最高优先级） |

括号 `( )` 可改变结合顺序。赋值 `=` **不是表达式**，只是语句（§6.1），因此 `a = b = 1` 非法。

## 6. 语句

### 6.1 语句种类

程序 = 顶层语句序列，自上而下执行；`func`、`type` 声明本身不产生输出。

```
赋值/表达式语句    x = 1           a[0] = 2        p.x = 3        f(1)
分支              if 条件 ... elif 条件 ... else ... end
当型循环          while 条件 ... end
遍历循环          for 变量 in 数组 ... end
循环控制          break        continue
函数定义          func 名字(参数...) ... end
结构类型定义      type 名字 = { 字段 = 默认值, ... }
返回              return [表达式]
```

- 每条简单语句以**换行**或 `;` 结束；连续空行与多余 `;` 视为空语句，允许。
- 赋值左侧必须是**变量 / 下标 / 字段**，否则报语法错误（如 `1 = 2`、`f() = 3`）。
- `if` 允许 0 个或多个 `elif`，最多 1 个 `else`，必须以 `end` 收尾。
- `for` 的遍历目标是数组，循环变量在每轮取一个元素；`break`/`continue` 只能在循环体内，`return` 只能在函数体内，否则报语法错误。
- 条件表达式**必须是 bool**（`if 1` 报运行时错误「条件必须是布尔值」）。

### 6.2 换行规则（关键，实现与写代码都必须遵守）

- 换行是**语句分隔符**。
- 在语法分析中：**表达式解析到"需要一个操作数"的位置时，跳过换行；解析到"需要一个运算符"的位置时，遇到换行即结束该表达式。**

由此：

```
sum = 1 +        // 合法：+ 之后需要操作数，换行被跳过
      2

x
+ 1              // 非法：x 已是一条完整语句，下一行以 + 开头无法成句
```

- `(`、`[`、`{`、`,` 之后需要操作数，因此多行书写数组/结构/参数列表天然合法：

```
var_list = [
    1,
    2,
    3,
]
```

### 6.3 完整语句示例

```
// 结构类型与函数
type Point = { x = 0, y = 0 }

func dist2(p, q)
    dx = p.x - q.x
    dy = p.y - q.y
    return dx * dx + dy * dy
end

// 分支
score = 87
if score >= 90
    grade = "A"
elif score >= 80
    grade = "B"
else
    grade = "C"
end
print("等级：" + grade)

// 当型循环
i = 0
while i < 3
    print(i)
    i = i + 1
end

// 遍历循环 + 数组 + 插值
nums = [3, 1, 4, 1, 5]
total = 0
for n in nums
    total = total + n
end
print("和 = ${total}，个数 = ${len(nums)}")

// 函数调用（递归）
func fib(n)
    if n < 2
        return n
    end
    return fib(n - 1) + fib(n - 2)
end
print(fib(10))
```

## 7. 语义细则

### 7.1 函数定义与调用

- **定义即注册**：语法分析阶段先登记全部顶层函数，因此**支持互相递归**、支持"调用写在定义之前"。
- 调用时实参个数必须等于形参个数，否则运行时错误。
- 参数**按值传递**：int/string/bool/null 复制；array/struct 传递引用（函数内修改元素、字段会影响调用方）。
- 函数执行到 `end` 或执行 `return`（不带表达式）都返回 `null`。
- **递归深度上限 1000**，超出报运行时错误「递归过深」（避免 JVM 栈溢出直接崩溃）。
- 不支持重载、默认参数、可变参数、匿名函数（v0）。

### 7.2 作用域

- 全局作用域 + 每个函数调用一个新的局部作用域（父作用域为全局）。
- 标识符解析：沿作用域链由内向外查找；查不到即运行时错误「未定义的变量 x」。
- 循环、`if` 块**不**产生新作用域（其内新建的变量属于所在函数/全局作用域），以保持实现简单、语义可预期。

### 7.3 赋值规则（无 var/let）

赋值 `名字 = 表达式` 时：

1. 若 `名字` 已存在于当前作用域链 → 修改**最近**的那一个（因此函数内可直接改全局变量）；
2. 否则在**当前（最内层）作用域**新建该变量。

### 7.4 数组与结构

- 下标从 **0** 开始；下标必须是 int；越界或负数下标报运行时错误「数组下标越界」。
- `push(arr, v)` 在尾部追加，返回新长度；`pop(arr)` 弹出并返回尾部元素，空数组报错。
- 结构：`type Point = { x = 0, y = 0 }` 声明后，`Point { x = 3 }` 得到 `y = 0`。
- 读取或赋值**未声明的字段**报运行时错误；访问字段时左侧不是 struct 也报错。
- 结构字段的**声明顺序**即打印顺序（§8）。

### 7.5 字符串插值

- `"共 ${ n + 1 } 条"`：`${` 与 `}` 之间是任意表达式，求值后按 `str()` 规则转成字符串拼接。
- `$` 不是 `${` 时可原样输出；需要字面 `${` 时写 `\${`。
- 插值表达式内不能出现未配对的 `}`。

## 8. 输出格式（黑盒测试的逐字节基准，必须严格遵守）

`print(参数1, 参数2, ...)`：各参数按 `str()` 转换后用**单个空格**连接，**末尾输出一个换行**；无参数时只输出一个换行。

`str(x)` 的转换规则：

| 值的类型 | 转换结果 | 示例 |
|---|---|---|
| int | 十进制，负数带 `-` | `-42` |
| string | 原文本，**不加引号** | `abc` |
| bool | `true` / `false` | `true` |
| null | `null` | `null` |
| array | `[` + 各元素**带引号的 repr** 用 `, ` 连接 + `]` | `[1, "a", [2]]` |
| struct | `类型名 { 字段 = repr, ... }`，按声明顺序用 `, ` 连接 | `Point { x = 3, y = 0 }` |
| function | `<func 名字>` | `<func fib>` |

其中**容器内**的元素用 repr 形式（字符串带双引号并对 `"`、`\`、换行转义），容器**外层**的字符串不加引号：

```
print("abc")            // abc
print(["abc", 1])       // ["abc", 1]
print(Point { x = 1 })  // Point { x = 1, y = 0 }
```

## 9. 内置函数

| 名称 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `print` | 任意个 | `null` | §8 |
| `input` | 0 或 1 个（提示串） | string | 先输出提示（不换行），读一行并去掉行尾换行；**读到 EOF 返回 null** |
| `len` | array / string | int | 元素个数 / 字符个数 |
| `int` | string / int / bool | int | 字符串须为可选 `-` + 数字，否则运行时错误；bool 转 0/1 |
| `str` | 任意 | string | §8 规则 |
| `type` | 任意 | string | 类型名，见 §4 |
| `push` | (array, 任意) | int | 尾部追加，返回新长度 |
| `pop` | array | 任意 | 弹出尾部元素；空数组报错 |
| `range` | `n` / `a, b` / `a, b, step` | array | 整数序列，左闭右开；`step` 不能为 0；`range(3)` → `[0, 1, 2]` |

调用不存在的函数、参数个数不符 → 运行时错误。

## 10. 运行方式、退出码与错误格式

### 10.1 命令行

```
java -cp build lbx.Main 脚本路径.lbx
```

或经封装脚本 `lbx.bat 脚本路径.lbx`。解释器**自身不打印任何多余内容**（无版本号、无调试信息、无计时输出），
正常结果只走 stdout，错误只走 stderr。

### 10.2 退出码

| 退出码 | 含义 |
|---|---|
| 0 | 程序正常执行完毕 |
| 1 | 词法 / 语法 / 运行时错误 |
| 2 | 命令行用法错误（未给脚本、文件不存在，等） |

### 10.3 错误消息格式

```
[LBX 词法错误] 行 3, 列 12: 未闭合的块注释
[LBX 语法错误] 行 7, 列 5: 期望表达式，实际遇到 'end'
[LBX 运行时错误] 行 12: 除零
[LBX 运行时错误] 行 20: 未定义的变量 total
```

- 行列号均为 **1 起算**；语法错误必须给出行、列，运行时错误至少给出行号。
- 每条错误一行；遇到第一个错误即终止（不做错误恢复）。
- 错误消息中的标识符与记号按原文给出。

## 11. 完整示例程序

### 11.1 规范写法（英文关键字，测试集与 AI 生成代码统一用此风格）

```lbx
// guess.lbx —— 猜数字（演示输入输出、分支循环、函数、数组、结构）
type Record = { name = "", score = 0 }

func judge(guess, answer)
    if guess == answer
        return "正确"
    elif guess < answer
        return "偏小"
    else
        return "偏大"
    end
end

func main()
    answer = 42
    history = []
    tries = 0
    while tries < 5
        guess = int(input("请输入数字："))
        tries = tries + 1
        push(history, guess)
        result = judge(guess, answer)
        print("第 ${tries} 次：${guess} → ${result}")
        if result == "正确"
            r = Record { name = "玩家", score = 5 - tries }
            print("猜中！得分 ${r.score}，历史 ${str(history)}")
            return
        end
    end
    print("机会用尽，答案是 ${answer}")
end

main()
```

## 12. 形式化文法（EBNF）

记号约定：`{ X }` 表示 0 或多次，`[ X ]` 表示可选，`|` 表示或，大写为词法记号，`"x"` 为字面记号。

```ebnf
program        → { NEWLINE } { top_stmt } EOF ;

top_stmt       → func_decl | type_decl | statement ;

(* ---------- 声明 ---------- *)
type_decl      → "type" IDENT "=" "{" [ field_defs ] "}" line_end ;
field_defs     → IDENT "=" expr { "," IDENT "=" expr } [ "," ] ;

func_decl      → "func" IDENT "(" [ params ] ")" line_end
                 { statement }
                 "end" line_end ;
params         → IDENT { "," IDENT } ;

(* ---------- 语句 ---------- *)
statement      → if_stmt | while_stmt | for_stmt
               | "break" line_end | "continue" line_end
               | "return" [ expr ] line_end
               | expr [ "=" expr ] line_end ;

if_stmt        → "if" expr line_end { statement }
                 { "elif" expr line_end { statement } }
                 [ "else" line_end { statement } ]
                 "end" line_end ;

while_stmt     → "while" expr line_end { statement } "end" line_end ;

for_stmt       → "for" IDENT "in" expr line_end { statement } "end" line_end ;

line_end       → ( NEWLINE | ";" ) { NEWLINE | ";" } ;

(* ---------- 表达式：优先级由低到高 ---------- *)
expr           → or_expr ;
or_expr        → and_expr { "or" and_expr } ;
and_expr       → not_expr { "and" not_expr } ;
not_expr       → "not" not_expr | equality ;
equality       → comparison { ( "==" | "!=" ) comparison } ;
comparison     → additive { ( "<" | "<=" | ">" | ">=" ) additive } ;
additive       → multiplicative { ( "+" | "-" ) multiplicative } ;
multiplicative → unary { ( "*" | "/" | "%" ) unary } ;
unary          → "-" unary | postfix ;
postfix        → primary { "." IDENT | "[" expr "]" | "(" [ args ] ")" } ;
args           → expr { "," expr } [ "," ] ;

primary        → INT | STRING | "true" | "false" | "null" | IDENT
               | "(" expr ")"
               | "[" [ args ] "]"                    (* 数组字面量 *)
               | IDENT "{" [ struct_fields ] "}" ;   (* 结构字面量 *)
struct_fields  → IDENT "=" expr { "," IDENT "=" expr } [ "," ] ;
```

> 文法中的 `NEWLINE` 依 §6.2 规则由语法分析器在"需要操作数"的位置自动跳过；
> 上表为便于阅读省略了该处理，实现时应统一在一个 `skipNewlinesInOperandPosition` 处处理，不要散落在各处。
